# Golden Palace Sound Master
Starter Android app for playing a local music file while monitoring microphone input simultaneously.

- Select music from device storage
- Play local music and adjust its volume
- Start/stop microphone monitor and adjust mic gain
- Stop all audio

Important: use wired headphones to reduce feedback. Android device/audio-route latency varies; Bluetooth monitoring may be delayed. This is a basic simultaneous music + mic monitor, not yet a full professional multi-channel DJ mixer.

Build requirements: JDK 17, Android SDK 35, Gradle 8.9, Android Gradle Plugin 8.7.3.
